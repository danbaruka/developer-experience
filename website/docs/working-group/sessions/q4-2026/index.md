# Developer Experience Working Group (Q4: Oct–Dec 2026)

## Purpose & Why

Q4 continues the DevEx Working Group with a sharper focus on **AI-native developer experience**: how Cardano repositories, docs, and tooling should be structured so both human contributors and AI agents can understand, test, review, and ship work safely.

## Session Plan (Sessions 22+)

|---------|-------|-------|--------|

## Session Details

### Session 22: How Can We Make Cardano Repositories Ready for AI Agents and AI Developers?
- **Objective**: Define a practical readiness model for Cardano GitHub repositories so agents can discover context, ground on truth, act with tests, and pass auto-checks, with **human verification always required** before merge.
- **Key Topics**:
  - Why generic AI fails on Cardano without repo-local context
  - The Discover → Ground → Act → Auto-verify → Human verify loop
  - Repo artifacts that matter: `README`, architecture maps, `AGENTS.md` / rules, blueprints, MCP, CI gates
  - Maintainer playbook: branch protection, CODEOWNERS, no auto-merge
  - Open discussion prompts
- **Deliverable**: [Session Notes](./22-ai-ready-cardano-repos/session-notes/readme.md) | [Resources](./22-ai-ready-cardano-repos/session-resources/readme.md)
